# ADR-001: TabBar 形态演进（跨页面公共方案）

> 状态：已定案 (2026-09-22)
> 决策者：Boss

## 决策背景
TabBar 经历了通栏、带随滚动渐显(fade)、最终定稿为悬浮胶囊形态。需要记录演进过程以防后续AI误改回旧方案。

## 决策内容
1. **废弃 fade 随滚动渐显机制**：新的液态胶囊设计核心在于「恒常可见」，产生实时折射反馈。
2. **浅色态参数裁决**：胶囊底 60% + 气泡加白描边与柔影。稿面 88% 经实机判定太厚，此为「文字标注为唯一真理」的例外。
3. **气泡单类实现**：App原生端不支持后代选择器，必须使用 `.tb-bub-light` 等单类。

## 第二部分：v4 材质与结构铁律（2026-09-28 老板拍板）

### 材质
- **胶囊**：`rgba(255,255,255,0.68)` + 顶部折光渐变 + 描边白 80% + `backdrop-filter: blur(20px)`
  （**App 端不可带 `saturate`**，否则整条失效，见 ADR-004）+ 白色光晕 `0 -6rpx 20rpx rgba(255,255,255,0.9)` + 上向柔影。
- **选中气泡**：浅态 `rgba(26,26,26,0.08)` / 暗态 `rgba(255,255,255,0.13)`，`96×44 r22` 内嵌，
  **无描边、无投影、无自身 backdrop-filter** —— 三者叠加会让它变成实心色块（v1 实测 L 0.55，比胶囊暗 0.32）。
- 未选中标签/图标 `#5F6B66`；选中 `tbTextOn`。

### 结构铁律：根节点＝胶囊本体
`.tb-bar` 自身 `position: fixed`，left/right/bottom/height **全由 `:style` 下发**。**禁止再套外层容器**，两条实测坑：
1. **零高度 `fixed` 父级（`height:0`）会把后代整棵裁掉**（Android ViewGroup 默认 clipChildren）
   → 屏幕上什么都不出现。曾误判为「TabBar 消失」，最后用红/蓝双色探针才定位。
2. **有真实高度的全宽层会吃掉屏幕底部整条的页面点击**（探针实测：带内命中 0、带外 2），
   且**无法绕过**（官方文档 App 平台明写父级 `pointer-events:none` 连子级一起屏蔽，见 ADR-004）。
→ 因此「全宽托底渐隐条」方案**永久否决**（页底内容预留已保证不钻到胶囊下）。

### 已否旧结论
- 气泡用 accent 淡染（`accentTint()` 已删）。
- 胶囊 52%（现为 68%）。
- 真机几何参考：物理 y 2508–2692（BAR_H 68.5dp × 2.79）；气泡宽 328px、槽心 x≈250 / 640 / 1030。
