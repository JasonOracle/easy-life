# ADR-003: 调试链路与防坑决策（防止 AI 重复踩坑）

> 状态：长期约束
> 决策者：架构组

## 决策背景
uni-app x + mp-weixin 环境下热重载和 automator 存在未记录坑位，易导致误判。

## 决策内容
1. **微信工具旧 JS 包问题**：WXML 更新但 JS 包未更新导致插值错乱。严禁据此修改业务代码，必须清缓存重启。
2. **新增组件热重载崩**：必须清缓存后重启小程序。
3. **窗口遮挡假象**：窗口被遮挡时截图和 DOM 探针失效。
4. **组件跨文件类名冲突**：组件内类名必须加前缀。
5. **宿主幻影副本**：特定情况下组件渲染出重复 DOM，勿盲目修改逻辑。
