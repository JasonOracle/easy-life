## 核心原则

**每种规格只做一张通用图，档位只改显示尺寸，不给每种食物各配图。**

- 14 张通用空器皿图（杯系 3 合 1、碗系 3 合 1）+ 4 张计数单位图（个/片/串）
- `pot` 按份 → 天平砝码 ×1/×2/×3
- 奶茶甜度 → 10 格电量条
- **餐次 → 同一片丘陵的四个时刻（方案B 实拍风光照）**：餐次是时间空间状态（天色 + 天体位置），不用食物区分

## 份量视觉换算

`h ∝ ∛amount`；宽高比沿用源图 `R = h/w`。`R≥1 → s = 9.0·∛amount`（高基准），`R<1 → s = 13.0·∛amount`（宽基准），再夹最大盒；amount≤1 固定高 66px。

## 工程备注

- 画板构建用「Insert 空壳 + `Replace(id, {...壳属性, children:[整棵树]})`」通路；`Insert` 直接挂子节点不进渲染管线。
- 照片填充用 `mode:'fill'`（没有 `cover`）；rectangle 无 `clip` 属性，圆角裁剪靠 `cornerRadius`。
- **Pencil 的 `assets/` 目录只在打开文档时建立索引**：会话运行中新增的图片文件渲染为棋盘格。运行中需要加图，放进文档目录的 `images/` 子目录（运行时可发现），或重启 Pencil 后再引用 `assets/`。
