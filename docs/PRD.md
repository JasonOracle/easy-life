## 2. 背景与目标

### 2.1 业务背景
- **市场趋势**：健康管理类App用户持续增长，2025年全球市场达$50亿
- **用户痛点**：现有竞品（MyFitnessPal、薄荷健康等）功能臃肿，核心体验不佳
- **机会点**：轻量级、极简录入、可视化反馈的健康管理工具存在市场空白

### 2.2 产品目标（SMART）
- **具体**：一款专注于"快速记录饮食+直观展示消耗"的卡路里追踪App
- **可量化**：
  - MVP版本支持记录5000+常见食物
  - 单次食物录入≤3步
  - 每日打卡完成率≥60%
- **时限**：MVP在6周内上线

### 2.3 用户画像

| 角色 | 核心诉求 | 使用场景 | 痛点 |
|------|---------|---------|------|
| 减脂人群 | 精准控制热量 | 餐后立即记录 | 现有App录入慢、食物库不全 |
| 健身人群 | 追踪蛋白质/宏量营养素 | 训练前后 | 缺乏可视化反馈 |
| 健康意识人群 | 了解日常饮食结构 | 日常用餐 | 操作复杂，难以坚持 |

## 3. 价值主张

**针对减脂人群**：
- **现状**：不知道吃了多少热量，难以控制摄入
- **解决方案**：3秒快速录入，自动计算卡路里
- **改变后**：清晰了解每日摄入，科学减脂

**针对健身人群**：
- **现状**：宏量营养素计算繁琐
- **解决方案**：一键记录，自动统计蛋白质/碳水/脂肪
- **改变后**：精准控制饮食，提升训练效果

## 5. 范围定义

### 5.1 MVP边界（Must）
- **核心功能**：
  1. 首页：今日摄入概览（总热量、宏量营养素）
  2. 添加食物：搜索/选择食物，填写份量
  3. 食物库：5000+常见食物数据
  4. 历史记录：按餐次查看

### 5.2 不包含范围（Won't）
- 用户注册/登录系统
- 社交功能
- 付费订阅
- 跨平台同步（MVP仅限单设备）

### 5.3 未来迭代（Could）
- 食物照片识别
- 饮食提醒
- 目标设定与调整
- 数据导出

## 6. 用户故事

### US-001: 快速添加食物
**作为**一个关注健康的用户  
**我想要**快速添加今天吃的食物  
**以便**准确追踪每日摄入  

**验收标准**：
1. 用户点击"添加食物"按钮
2. 弹出搜索框，输入食物名称
3. 搜索结果实时过滤
4. 点击食物，填写份量（克/份）
5. 确认添加，返回主页更新数据

### US-002: 查看今日摄入
**作为**一个想要控制饮食的用户  
**我想要**直观看到今日摄入总量  
**以便**判断是否超标  

**验收标准**：
1. 首页顶部显示今日总热量
2. 环形图展示摄入进度（目标vs实际）
3. 下方显示宏量营养素分布
4. 按餐次分类显示记录

### US-003: 查看历史记录
**作为**一个想分析饮食趋势的用户  
**我想要**查看过去7天的记录  
**以便**调整饮食计划  

**验收标准**：
1. 提供日历/列表两种视图
2. 显示每日热量变化趋势图
3. 可点击某日查看详细记录

## 7. 详细功能说明

### 7.1 首页模块

**功能描述**：展示今日摄入概览

**前置条件**：用户已打开App

**主流程**：
1. App启动，显示首页
2. 顶部展示今日日期和问候语
3. 中央环形图：总热量 + 目标对比
4. 下方三栏：蛋白质/碳水/脂肪
5. 底部：今日餐次列表（早/中/晚/加餐）
6. 右下角悬浮"添加食物"按钮

**UI规范**：
- 主色：#4CAF50（绿色，代表健康）
- 目标设定：1800 kcal（可配置）
- 环形图进度：超过100%变红色警告

### 7.2 添加食物模块

**功能描述**：记录饮食摄入

**主流程**：
```
点击"添加食物"
    ↓
进入搜索页
    ↓
输入食物名称
    ↓
搜索结果展示（图片+名称+卡路里）
    ↓
点击选择食物
    ↓
弹出份量选择器
    ↓
确认添加
    ↓
返回首页更新数据
```

**份量选择器设计**：
- 默认单位：克（g）
- 快捷选项：小份/中份/大份
- 自定义输入：支持任意重量

### 7.3 食物库模块

**数据结构**：
| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 唯一标识 |
| name | string | 食物名称 |
| calories | int | 每100g卡路里 |
| protein | float | 蛋白质(g/100g) |
| carbs | float | 碳水(g/100g) |
| fat | float | 脂肪(g/100g) |
| category | string | 分类（水果/蔬菜/肉类等） |

**MVP食物库规模**：5000条常见食物

## 8. 非功能需求

### 8.1 性能
- App启动时间 ≤ 2秒
- 食物搜索响应 ≤ 300ms
- 本地数据存储，无需网络

### 8.2 兼容性
- iOS 14+
- Android 8.0+
- 支持深色模式

### 8.3 安全
- 所有数据本地存储
- 无用户信息收集
