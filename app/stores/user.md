# user.ts — 用户 store

## 💡 核心思想

昵称＋连续记录天数，个人中心头图消费，昵称可改并持久化。

## 💻 使用示例

```ts
const user = useUserStore()
user.setName('阿绿')
```

## 依赖

- 本地存储 `ct_user_v1`；被个人中心依赖（后续接线）

## 设计决策

- streakDays 暂为演示值 128，后续由 food entries 按日推导真实连击
- 空昵称拒绝写入
- **默认名＝「轻律生活」**（2026-09-28，原「老刘」）。**存量设备的历史值「老刘」按「未自定义」处理**：
  `loadName()` 读到 `LEGACY_PLACEHOLDER = '老刘'` 时直接返回新默认名——昵称已落盘在 `ct_user_v1`，
  只改默认值在这类设备上永远不生效，必须做这层替换。

## 边界与降级

- 存储失败回落默认名「轻律生活」（2026-09-28 起；原「老刘」）

## 与设计稿的对应

- 个人中心「轻律生活／已连续记录 128 天」（2026-09-28 头像与默认昵称一并换新）
