# MealIcon.uvue — 餐次图标

## 1. 用途

「今日餐次」时间轴里的餐次标识图标（早餐/午餐/晚餐/加餐四变体），同时承担"该餐次有没有记录"的状态表达。

## 2. 依赖

| 方向 | 对象 | 说明 |
|---|---|---|
| 依赖 | Ardot 节点 `3:80` `3:96` `3:106` `3:116` | 四个图标的几何与配色实测来源 |
| 被依赖 | `pages/home/Home.uvue` | 餐次时间轴 |

## 3. 设计决策

- **底色即状态**：`active=true` 薄荷渐变 `#7DEBC7→#1FBF8F` + 白 50% 内描边（有记录）；`false` 灰绿 `#DCE9E3` + 白 60%（未记录）—— 设计稿「加餐」行就是灰色底 + 「未记录」文案。
- **符号层用 CSS 近似**：设计稿符号是 SVG 矢量（太阳/月牙/碗/曲奇），uvue 画不了 path。用圆/椭圆/圆弧按设计稿**原坐标**（如午餐白圆环 25@8.5,8.5）CSS 还原，形似度优先。
- **符号与状态解耦**：符号只按 `type` 切换，与 active 无关（灰色曲奇也是白圆+灰点）。

## 4. 边界与降级

| 场景 | 处理 |
|---|---|
| 未知 type | 无符号渲染，只剩底色块（不崩溃） |
| 低端机 | 纯静态 CSS，无动画，无降级需求 |
| 后续 iconfont 接入 | 符号层整体替换为 SVG 字体图标，底色逻辑不变 |

## 5. 与设计稿的对应

- Ardot：`3:80`（早餐碗线）、`3:96`（午餐太阳）、`3:106`（晚餐月牙）、`3:116`（加餐曲奇）
- 尺寸：42×42 r13（VisualLanguage §9 组件速查），内描边 40.8@0.6 白 50%
- **注意**：设计稿渐变硬编码 `#7CEBC6`（旧值），按 Boss 裁定用变量新值 `#7DEBC7`
- **近似项**：碗/月牙为 CSS 近似，与矢量原稿有形差；iconfont 接入后重绘
