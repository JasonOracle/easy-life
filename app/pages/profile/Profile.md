# Profile.uvue — 个人中心

## 1. 用途

展示长期指标与趋势：液体头图（身份）+ 本周概览七颗液滴 + 历史趋势柱状图 + 历史列表。

## 3. 设计决策

- **头图用液体隐喻**：首页的瓶子是「容器」，二级页头图是「容器里倒出来的液体」，两者是同一隐喻的上下游。底部用 **SVG 波浪收边**（不是直线）——删掉波浪就退回普通渐变头图。
- **气泡数量**：本页 **3 颗**（8/6/5px）；设置页只有 **2 颗**（7/5px）——设计稿实测差异，不是笔误。
- **信息去重铁律**：头图只放**长期指标**（累计记录 / 日均摄入）；「今日摄入 / 还能吃」下放到卡片区并与首页瓶子共用同一数据源，**不得写死**。

## 4. 边界与降级

| 场景 | 处理 |
|---|---|
| 新用户（累计记录 = 0） | 头图统计条显示 0，周概览七颗液滴全为「空缺」态 |
| 全部超标 | 液滴全珊瑚 `#FF9E7D`，徽章不显示「达标 N 天」 |
| 长用户名 | 单行省略 |
| 低端机 | 液滴 `dropBob` 浮动动画关闭 |
