# Settings.uvue — 设置页

## 💡 核心思想

设置页是**纯展示 + 预留动作**的页面：v1.0 只做静态呈现（开关状态、chip、值都是展示位），**不接 settings store**，避免为未实现的功能造状态。

三个刻意的设计决定：

1. **未上线功能用「即将上线」chip 占位**，不用禁用的开关——设计稿就是这么约定的（`用餐提醒` / `餐次管理`）。这样用户看得懂「有这个东西，但还没做」，而不是「坏了」。
2. **深色模式 v1.0 不做**（`AGENTS.md` 核心约束），设计稿给的是普通 off 开关，视觉照做、行为不接。
3 **危险项独立成组**：白底不透明 + 珊瑚描边 `#F5D5C8` + 珊瑚阴影，与其余玻璃卡在材质上区分开；且**设计稿没有箭头**（不可跳转页，直接触发清除）。

数据流：本页唯一真实数据是 `useGoalStore().calorieGoal` → 「每日热量目标」行右侧 `1800 kcal`。其余行均为静态。

## 💻 使用示例

由 `pages.json` 路由挂载。⚠️ **当前全项目没有入口导航到本页**（无任何 `uni.navigateTo({ url: '/pages/settings/Settings' })`），需从「我的」页补一个入口。

```ts
uni.navigateTo({ url: '/pages/settings/Settings' })
```

页内数据消费：

```ts
import { useGoalStore } from '../../stores/goal.uts'
const goalStore = useGoalStore()
// 模板：「每日热量目标」行右侧 {{ goalText }} kcal
```

## 边界与降级

| 场景 | 处理 |
|---|---|
| 未上线功能 | 「即将上线」chip，不接行为 |
| 深色模式 | v1.0 不做，仅展示 off 开关 |
| 图标 | CSS 圆形占位（设计稿为 16×16 线性图标，iconfont 接入后替换） |
| 小程序胶囊 | 状态栏高度胶囊自适应（同首页），hero 高度随之缩短 |
| 波浪 | CSS 椭圆近似设计稿 SVG path（形差已标注） |
