# Settings.uvue — 设置

## 1. 用途

偏好开关、目标管理入口、数据备份/恢复、危险操作（清空数据），以及页脚版本信息。

## 2. 依赖

| 方向 | 对象 | 说明 |
|---|---|---|
| 依赖 | `stores/settings.ts` | 深色模式（占位）、用餐提醒、音量（*待实现*） |
| 依赖 | `stores/goal.ts` | 跳转目标设置 Modal（*待实现*） |
| 依赖 | `stores/device.ts` | 低端机降级 |
| 被依赖 | `pages.json` | 第 3 条路由；从「我的」页 `navigateTo` 进入 |

## 3. 设计决策

- **危险项独立成组**，不与常规项混在同一张卡里（独立卡片 + 珊瑚描边 `#F5D5C8` + 珊瑚阴影 `#E0633C` 8%）。
- **分组顺序固定**：偏好 → 目标管理 → 数据管理 → 危险项 → 页脚。
- **副标题只写非显而易见的信息**（如「早中晚各提醒一次」「当前 1800 kcal」）；名称已自解释的项（深色模式、餐次管理）**不配副标题**。
- **头图气泡 2 颗**（7/5px），比「我的」页少一颗。
- **图标底座是 28×28 单色浅底正圆**，不是彩色渐变方块。

## 4. 边界与降级

| 场景 | 处理 |
|---|---|
| 深色模式 | **v1.0 不做**：开关置灰并标「即将上线」 |
| 清空数据 | 二次确认；确认后回到「新用户」态 |
| 备份/恢复 | v1.0 待定实现方式，**不编造 API** |
| 低端机 | 玻璃卡降级为半透明白 + 描边 |
