# CalTrack — 卡路里管理 App

轻量级卡路里追踪 App，快速记录饮食，直观展示摄入数据。

## 当前状态

**设计完成，开发未开始。** 8 屏高保真 UI 已在 Ardot 完成，交互原型 v18 已落地。

## 技术栈

uni-app x + Vue3 + TS + Pinia，本地存储，无服务器。

## 视觉方向

薄荷液滴（Mint Drop）—— 记完一顿饭，水位涨一截、晃两下、归于平静。
