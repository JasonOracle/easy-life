## 0. 为什么推翻 v2.0

v2.0 做了一套完整的「Apple 材质主义」：Apple Watch Move 环配色、visionOS 光学玻璃、Apple 标准弹簧曲线、iOS System Colors 原值。

**问题：它 100% 由 Apple 的既有资产构成，没有一个字节属于 CalTrack。**

这是"最高级的平庸"——精致、每个参数都对、但完全可预测。更致命的是战略层面：Apple 自己就有健康 App 和活动环，我们等于主动站进巨人的影子，而且是在它的主场。

用户看到的第一反应会是"做得挺像 Apple"，**而不是"这个 App 有点意思"**。前者不产生下载动机。

> 参考：Anshu Chimala（Apple R&D 设计负责人 12 年）——
> "Great design starts with feeling and aims to create an emotional response."
> 详见 `CalTrack_DesignCritique_Lenny.md`

## 1. 情感北极星（Emotional North Star）

> **记完一顿饭，水位涨一截、晃两下、归于平静——
> 让用户心里踏实：今天吃了多少，还剩多少，我清楚。**

这是整个产品的情感锚点。所有设计决策都要回到这句话做判断。

### 关键推论

| 要 | 不要 |
|---|---|
| 安静的收敛（晃动 1.7s 内归于平静） | 撒花、弹窗、庆祝动画 |
| 温和的提醒（超标用珊瑚色，不是刺眼红） | 制造焦虑的警示 |
| 看得见的"过程"（倒进去、晃、平） | 干巴巴的数字跳变 |
| 清新轻松（薄荷、留白、透亮） | 沉重、专业感、医疗感 |

> **反面教材**：火焰方向被否掉的理由——它天然带紧张感，每天提醒一次"你又超了"，用三天就想卸载。卡路里 App 是要天天开的，不能让人有压力。

## 2. 核心隐喻：瓶子装液体

卡路里是个抽象数字，需要一个**看得见的容器**来装它。选「瓶子」的三个理由：

1. **语义最准** —— 卡路里就是"吃进去"，用"倒进瓶子"是最直觉的比喻，用户零学习成本
2. **能贯穿整个 App** —— 瓶子=容器，数字=水位，超标=溢出，第二天=倒空重来。一套隐喻撑起全部界面
3. **没人占着** —— 它不是 Apple / Fitbit / 薄荷健康的资产，别人抄了就是抄你

### 隐喻映射表

| 概念 | 瓶子的表达 |
|---|---|
| 今日摄入 | 瓶内液体高度 |
| 每日目标 | 瓶身容量（瓶口 = 100%） |
| 添加食物 | 往里倒一点水，水位涨一截 |
| 删除记录 | 水位降回去，同样晃两下 |
| 超标 | 液体转珊瑚色，瓶身描边变暖 |
| 新的一天 | 瓶子倒空，重新开始 |
| 历史趋势 | 一排小瓶子，各自水位不同 |

## 3. 色板：薄荷

### 3.1 液体主渐变（品牌资产）

```
#7DEBC7  →  #1FBF8F  →  #0D9C73
 液面浅      液体主体     瓶底深
```

上浅下深，模拟真实液体的体积感（光从上方来）。

| Token | 值 | 用途 |
|---|---|---|
| `--ct-e1` | `#7DEBC7` | 液面高光、浅色填充 |
| `--ct-e2` | `#1FBF8F` | 液体主体、按钮底、激活态 |
| `--ct-e3` | `#0D9C73` | 瓶底深、渐变终点 |

### 3.2 系统语义色

| 名称 | 值 | 用途 |
|---|---|---|
| Blue | `#38A3F5` | 链接、次要操作 |
| Green | `#1FBF8F` | 达标状态（同主色） |
| Amber | `#E8B54D` | 接近上限（剩余 ≤ 200） |
| **Coral** | `#FF9E7D` | **超标 —— 温和，不刺眼** |
| Purple | `#A88BE8` | 预留（营养素） |

> **超标用珊瑚而不是红**：情感目标是"踏实"不是"警醒"。`#FF453A` 那种纯红会制造焦虑，珊瑚色既传达了"超了"，又不吓人。

### 3.3 灰阶与文字

| Token | 值 | 用途 |
|---|---|---|
| `--ct-bg` | `#F2FAF5` | 页面底（极淡薄荷） |
| `--ct-glass` | `rgba(255,255,255,.74)` | 玻璃卡片 |
| `--ct-sep` | `rgba(18,110,85,.10)` | 分隔线（0.5px hairline） |
| `--ct-label` | `#0A4F3D` | 主文字（深墨绿） |
| `--ct-label-2` | `rgba(15,79,61,.60)` | 次级文字 |
| `--ct-label-3` | `rgba(15,79,61,.34)` | 占位、未激活 |

> 主文字用**深墨绿而非纯黑**——配合薄荷主题，比纯黑更统一，也比灰色更有精神。

### 3.4 文字/背景分级规则（重要）

薄荷绿 `#1FBF8F` 在白底上对比度只有约 2.3:1，**不能直接用于小字**。

| 场景 | 用哪个色 |
|---|---|
| 小字强调（≤ 15px） | `#0A7A5C`（深，可读） |
| 大数字 / 标题 | `#0A4F3D` |
| 按钮底 / 标签底 | `#1FBF8F`（配白字，对比度够） |
| 渐变 | `#7DEBC7 → #0D9C73` |

### 4.1 几何

```
SVG viewBox: 0 0 120 168     容器显示尺寸: 132 × 185 px

瓶盖   x=44  y=2   w=32 h=13  rx=4   #CFEDE2
```

### 4.2 玻璃材质

```css
fill: rgba(255,255,255,.42);
stroke: rgba(255,255,255,.9);
stroke-width: 1.2;
filter: drop-shadow(0 8px 20px rgba(13,120,90,.14));  /* 薄荷色投影，不是黑 */
```

高光（两条，模拟玻璃反光）：
- 主高光：`x=23 y=38 w=9 h=92 rx=4.5`，`rgba(255,255,255,.55)`
- 次高光：`x=92 y=52 w=4 h=58 rx=2`，`rgba(255,255,255,.32)`

瓶身外薄荷光晕：
```css
radial-gradient(circle, rgba(31,191,143,.18) 0%, transparent 68%);
filter: blur(10px);
```

### 4.3 数字排布

数字**在瓶子下方**，不在瓶内（瓶内放数字会被液体干扰，读不清）。

## 5. 液体动画（本版核心）

### 5.1 水位

```js
translateY = (1 - pct) × 132     // 0 = 满瓶，132 = 空瓶
transition: transform 1.15s cubic-bezier(.22,1,.36,1)
```

### 5.2 波纹

液面用 **34 段采样**的正弦波，2 个完整周期：

```js
y = 28 - amp × sin((i/34) × 2π × 2 + phase)     // 波峰向上 = y 减小
```

### 5.3 时序：倒进去 → 晃两下 → 平整

| 阶段 | 时间 | 振幅 |
|---|---|---|
| 注入 | 0 ~ 1.15s | 水位上升（CSS transition） |
| 激起 | 瞬间 | amp 冲到 6.5 |
| 晃动 | ~1.7s | 按 0.955/帧指数衰减 |
| 平静 | 结束 | amp < 0.06 归零，液面完全水平 |

```js
waveAmp *= 0.955;          // 每帧衰减
// 6.5 → 0.06 约需 100 帧 ≈ 1.67s @60fps
wavePhase += 0.17;         // 波形横向推进
```

> **衰减系数是情感开关**：`0.955` 让它 1.7 秒内安静下来，这才有"踏实感"。
> 改成 `0.99` 会晃 6 秒以上，变成"躁动"，与情感目标冲突。

### 5.4 触发时机

| 操作 | 动画 |
|---|---|
| 添加食物 | 水位升 + splash(6.5) |
| 删除记录 | 水位降 + splash(4.5)（轻一点） |
| 修改目标 | 水位重算 + splash(5) |
| 首次进入 | 直接设定水位，**不晃动**（安静开场） |

## 8. 交互反馈矩阵

原则不变：**触摸 → 立即有反馈（≤100ms）→ 过程可见 → 结果明确**。

| # | 交互 | 即时反馈 | 过程反馈 | 结果反馈 |
|---|---|---|---|---|
| 1 | 任意可点元素按下 | 缩放至 .945 回弹 | — | — |
| 2 | 主操作按下 | 按压 + 触点波纹 | — | — |
| 3 | Tab 切换 | 图标弹跳（-7px, 1.22×） | 页面上浮淡入 | 激活态变薄荷 |
| 4 | 弹窗打开 | — | 弹簧上滑 + 逐项 stagger (40ms) | — |
| 5 | 选食物 | 卡片打勾弹跳 | 180ms 后关闭 | 顶部热量区数字滚动 |
| 6 | 选分量 / 餐次 | 弹跳 1.13× | 外扩光环 | 选中薄荷底 |
| 7 | 长按条目 | 500ms 后震动 | 删除按钮弹出 | 进入删除模式 |
| 8 | 删除条目 | 触觉 24ms | 右滑 72px + 缩至 .88 淡出 | **水位下降 + 轻晃** |
| 9 | **确认添加** | 触觉 18ms | — | **水位上升 + 晃动 + 归平** |
| 10 | 主数字变化 | — | odometer 滚动 750ms | 水位平滑变化 |
| 11 | 超标 | — | 液体转珊瑚 + 瓶身描边变暖 | 数字变色 |
| 12 | Toast | 触觉 10ms | 底部弹入 | 1.5s 后消失 |

### 8.1 触觉分级

```js
haptic(6)    // 轻触
haptic(12)   // 选中
haptic(20)   // 确认
haptic(24)   // 破坏（删除）
```

> `navigator.vibrate` 仅 Android。iOS 需 uni-app x 调 `uni.vibrateShort()`。

## 9.5 二级页面：我的 / 设置（v3.1）

### 9.5.1 液体头图

「我的」和「设置」共用一套头图语言 —— 首页的瓶子是**容器**，二级页的头图是**容器里倒出来的液体**，两者是同一个隐喻的上下游。

| 参数 | 我的 | 设置 |
|---|---|---|
| 内边距 | `52px 20px 60px` | `52px 16px 32px` |
| 渐变 | `160deg #3ED9A7 → #12A87E(48%) → #0D9C73` | `160deg #3ED9A7 → #12A87E(55%) → #0D9C73` |
| 顶部光晕 | `radial 400×260 at 82% -10%`，`rgba(125,235,199,.42)` | `radial 320×200 at 84% -12%`，`rgba(125,235,199,.40)` |
| 底边 | SVG 波浪收边，填充 `#F2FAF5`，高 46px | 同，高 40px |
| 气泡 | 3 颗（76 / 34 / 15px），`rgba(255,255,255,.16)` + 内高光 | 1 颗，64px |

> **波浪不是装饰**。它让头图与内容区的交界不是一条直线，而是一道液面 —— 这是液体隐喻在二级页唯一的落点。删掉就退回普通渐变头图。

### 9.5.8 食物选项行：甜度分段控件（v3.3）⭐

**触发规则**：选项行**按所选食物自动出现**——选奶茶出现甜度，选苹果不出现。绝不常驻。

| 元素 | 规格 |
|---|---|
| 位置 | 分量行之后、餐次行之前 |
| 标签 | 与「分量/餐次」同一 `.form-label`（60px，15px/500） |
| 分段控件 | 5 档等分，gap 5，圆角 11，padding `8px 0` |
| 未选中 | `rgba(120,140,130,.09)` 底，`--ct-label-2` 字，12.5px/500 |
| 选中 | `rgba(31,191,143,.15)` 底 + `inset 0 0 0 1px rgba(31,191,143,.4)` 描边，`#0A7A5C` 字，600 |

| Hint | 10.5px / `--ct-label-3` / 左侧缩进 60px 对齐标签，**必写估算说明** |
| 估算角标 | 10px，`--ct-label-3`，`rgba(120,140,130,.32)` 0.5px 描边，圆角 5 |

**杯型（vessel）显示**：分量项文字后跟容量小字（10.5px / `--ct-label-3`），例「中杯 500ml」；
vessel 模式下分量行**隐藏「＋」**（杯型不可自定义）。

改后标「已调整」，换配置自动回到库值——不污染食物库。

### 9.5.9 选项图标系统（v3.4）⭐

**原则：图标不是装饰，是量尺。** 文字「中杯 500ml」要读，液面高度是**一眼**的——
与瓶子隐喻同源：都是"看得见的量"。

| 选项 | 图标 | 随档位变化的量 |
|---|---|---|
| 杯（小/中/大杯） | 带吸管的杯 + 液体 | 液面高度 `f` 0.34 → 0.65 |
| 碗（小/中/大碗） | 碗 + 液体 | 液面高度 `f` 0.34 → 0.65 |
| 个 / 颗 / 根 | 圆 + 实心内圆 | 内圆半径 2.6 → 5.0 |
| 份 / 盘 | 椭圆盘 + 内椭圆 | 内椭圆 `ry` 1.6 → 3.8 |
| **甜度 5 档** | **糖粒堆** | 颗粒数 **0 / 2 / 3 / 4 / 5**（无糖 = 虚线空心圈） |
| 餐次 | 日出 / 太阳 / 月牙 / 曲奇 | 名称映射，时钟兜底 |

**规格**

| 项 | 值 |
|---|---|
| viewBox | `0 0 26 22`，容器 26×22 |
| 描边 | 1.5px，`currentColor`，圆头圆角 |
| 颜色 | 未选中 `rgba(120,140,130,.75)`；选中 `#0A7A5C` |
| 液体 | 薄荷渐变 `#7DEBC7 → #0D9C73`，`clipPath` 裁剪（**id 用递增计数器，防重复渲染冲突**） |
| 糖粒 | `r=1.65`，底行 `y=9.7` / 上排 `y=5.1`，间距 4.4；未选 `rgba(120,140,130,.45)`，选中 `#fff` |
| pill | `flex:1 1 0` / `min-width:54px` / 纵向（图标+文字）/ 圆角 12 / padding `9px 4px` |
| pill 底 | 未选 `rgba(120,140,130,.07)`；选中 `rgba(31,191,143,.15)` + `inset 0 0 0 1px rgba(31,191,143,.4)` |
| 文字 | 12.5px / 500；选中 600 + `#0A7A5C` |

**动画（每次切换都播）**

| 触发 | 动画 |
|---|---|
| 点击任意选项 | `press` 缩放 .94 + 触点波纹 + 触觉 12ms |
| 选中 | `ctPick` 弹跳 + 外扩光环 |
| 分量 / 杯型切换 | **液体升起** `liqRise .52s`：`scaleY(.06) → 1`，`transform-box:fill-box` / `origin:bottom` |
| 甜度切换 | **糖粒落下** `sdDrop .44s`：每颗自 `translateY(-6px) scale(.4)` 落下，stagger 45ms |
| 热量变化 | 数字 `scale(1.085)` 弹跳 `.42s`；确认后液滴晃动 |

> `transform-origin` 与 `transform-box:fill-box` 是 SVG 内元素做 transform 动画的前提，
> 缺了会绕整个 SVG 画布原点缩放，看起来像"飞进来"。

**搜索空态（自建食物入口，v1.1 预留）**：52px 水滴 SVG（opacity .55）+「没找到「xxx」」
+ 副文案「可以自己创建这个食物 / 创建后下次就能直接添加」+「＋ 自己创建」胶囊
（`rgba(31,191,143,.13)` 底 + inset 描边，13px/600 `#0A7A5C`）。

## 11. 性能与跨端降级（uni-app x 的现实约束）

| 问题 | 降级方案 |
|---|---|
| `backdrop-filter` 原生渲染下可能不支持 | 「半透明纯色 + 亮边 + 分层阴影」模拟玻璃 |
| 多层 blur 掉帧 | 同屏 blur ≤ 3 层；弹窗全屏时暂停下层 |
| **液体 rAF 动画在低端机掉帧** | 降级：去掉波纹，只保留水位 transition（视觉损失很小） |
| 真实食物图体积（180×30KB ≈ 5.4MB） | WebP + LRU（≤20MB）+ 按需解码 |
| 弹簧动画在低端安卓 | 降级为 opacity + 短时长 |

**建议**：骨架搭好后**第一时间真机验证**两件事 —— ① `backdrop-filter` ② 液体 rAF 的帧率。
